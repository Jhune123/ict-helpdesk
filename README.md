# 🧰 KSU ICT Helpdesk & Asset Management System

This system was developed for **Kalinga State University ICT Office** to manage technical support tickets, monitor device repairs, and track IT assets.  
It provides a centralized platform for handling service requests, assigning IT personnel, and generating reports.

---

## 🚀 Features

- Ticket creation and tracking (repair, maintenance, and support requests)
- Assign IT personnel to each ticket
- Department and category management
- Real-time ticket status updates
- User roles and authentication (Admin, IT Staff, Client)
- Dashboard with analytics and charts
- Asset and equipment tracking
- Responsive design using **Tailwind CSS** and **Blade**

---

## 🛠️ Built With

- **Laravel** 11
- **Tailwind CSS**
- **MySQL** (Database)
- **Vite**
- **Blade Templates**

### Local development assets

Vite HMR uses `localhost` by default so its CSS and JavaScript load when the app is opened at `http://localhost:8000`, even if the computer's network address changes. To use Vite from another device on the local network, set `VITE_HMR_HOST` in your local `.env` to this computer's LAN IP address and restart `npm run dev`.
